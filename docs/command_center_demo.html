Enterprise Platform Visualizer

This UI demonstrates how enterprise orchestrators manage multi-agent workflows with inspector quality gates.

  • Clickable Stages: Click any phase card at any time to view its persisted thoughts & inspector audit history.
  • 5 Phases: Foundation ➔ Framing ➔ Roofing ➔ Exterior ➔ Interior.
  • Inspector Gate: Runs after each sub-agent completes work.
  • Repair Loop: If inspector flags FIX REQUIRED, the orchestrator dispatches `action: repair` back to the sub-agent before re-inspecting.
